# Ledger Bridge

Двусторонняя сверка двух реестров с объяснимыми исключениями. Самостоятельное демо на вымышленных документах и суммах; не бухгалтерское подтверждение и не интеграция с рабочей системой.

```sh
python bridge.py
python -m unittest discover -s tests -v
```

Python 3.12+, без зависимостей. Результат — `build/reconciliation.json` и `build/exceptions.csv`. Сохранённый пример — в `examples/`.

## Правила сопоставления

Ключ: нормализованный reference + валюта. У reference обрезаются внешние пробелы и меняется регистр, остальные символы сохраняются. Валюта — трёхбуквенный код без конвертации курсов. Денежные значения считаются через Decimal, не float; допустимы знаковые суммы до двух знаков после точки.

Статусы: `matched`, `amount_mismatch`, `left_only`, `right_only`, `ambiguous_duplicate`. При нескольких строках ключа хотя бы с одной стороны соответствие не угадывается, даже если суммы групп совпадают. Пропущенная сумма отклоняется, а не заменяется нулём.

Контрольные итоги считаются отдельно по валюте и всем валидным строкам, включая неоднозначные. Они не доказывают попарное соответствие. Строки с ошибками учитываются отдельно, что позволяет сверить входные количества с принятыми и отклонёнными.

В примере: два совпадения, одно расхождение суммы, один левый остаток, один правый остаток, один неоднозначный ключ и одна отклонённая входная строка. Все дефекты созданы намеренно.

## Ограничения

Не выполняются fuzzy matching, распределение одной оплаты по нескольким документам, пересчёт валют и выбор действующей версии документа. Эти правила требуют отдельного контракта. Реестры загружаются в память. Формат CSV фиксирован: `reference,currency,amount`. Корпоративный код, рабочие документы и их идентификаторы не переносились.
