# Report Kit

Генератор самостоятельных HTML-отчётов из JSON. Четыре типа блоков: KPI, текст, таблица и горизонтальная диаграмма. Результат открывается без сервера, JavaScript, шрифтов из сети и сторонних библиотек.

## Запуск

Python 3.12+, внешних зависимостей нет:

```sh
python report.py examples/report.json --output build/report.html
python -m unittest discover -s tests -v
```

Откройте `build/report.html` в браузере. Встроены адаптивная сетка, семантические таблицы, текстовые подписи диаграммы и стиль печати.

## Инженерная часть

- Контракт документа версионирован: `version: 1`.
- Ограничены размер JSON, количество блоков, ширина/длина таблиц и диапазон значений диаграммы.
- Дубли JSON-ключей и нечисловые значения NaN/Infinity отклоняются.
- Все пользовательские строки проходят HTML-экранирование; произвольные HTML, URL, CSS и скрипты из входа не исполняются.
- В HTML включена CSP, запрещающая загрузки ресурсов, формы и скрипты. Встроенные стили разрешены.
- Рендер детерминирован: одинаковый документ даёт одинаковый HTML.

Числа демо согласованы с примером Operations Analytics, но JSON здесь является отдельной презентационной фикстурой, а не результатом автоматического подключения к пайплайну.

## Ограничения

Это CLI-демо, без визуального редактора, учётных записей, хранения версий и LLM. Экранирование и CSP не являются заявлением о прохождении независимого аудита безопасности. Все данные вымышлены, оформление нейтральное, исходники написаны как самостоятельное демо.
