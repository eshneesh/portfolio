# Проверка пакета

Дата: 9 ноября 2026 года. Локальная среда: Windows, Python 3.14. В README и CI указана целевая минимальная версия Python 3.12; отдельный запуск под 3.12 и на Linux не выполнялся.

| Проект | Проверка | Результат |
|---|---|---|
| Operations Analytics | 6 unit-тестов, запуск CLI, сверка демометрик | Пройдено |
| Report Kit | 5 unit-тестов, генерация HTML, просмотр в браузере | Пройдено |
| Service BI Lab | 3 unit-теста, создание SQLite и выполнение двух SQL-запросов | Пройдено |
| Local Knowledge Search | 5 unit-тестов, индексация, 8 оценочных запросов | Пройдено |
| Source Atlas | 4 unit-теста, профиль двух CSV, проверка JOIN и загрузка SQLite | Пройдено |
| Ledger Bridge | 5 unit-тестов, сверка двух синтетических реестров | Пройдено |
| Cohort Compass | 6 unit-тестов, когорты и ABC/XYZ для пяти вымышленных аккаунтов | Пройдено |

Итого: 34 unit-теста. Архивы проверяются после распаковки в новый каталог: тесты и CLI не используют исходные рабочие папки. Поиск верно обработал 8 из 8 небольших авторских примеров, включая два запроса без результатов; это не внешняя оценка качества на реальных данных.

В HTML визуально проверены заголовок, KPI, диаграмма и таблица на широкой странице. Узкий экран и печатный вывод отдельно не просматривались. M/DAX не исполнялись в Power BI Desktop. GitLab CI подготовлен; серверные pipeline GitLab/GitHub в эту локальную проверку не входили.

Чувствительные источники не открывались и бизнес-скрипты из рабочих репозиториев не запускались в ходе сборки этого набора. В набор вошли только новые демонстрационные исходники и их результаты. Отдельные проверки обезличивания — в `sanitization-report.json`.
