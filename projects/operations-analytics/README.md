# Operations Analytics

Воспроизводимый Python-пайплайн для анализа обращений на полностью синтетическом наборе данных. Демонстрационный проект, не производственная система.

Показывает работу с контрактом источника, отбраковку неоднозначных записей, точные денежные суммы, явные знаменатели метрик и проверяемое происхождение результата.

## Запуск

Python 3.12+, без внешних зависимостей:

```sh
python pipeline.py
python -m unittest discover -s tests -v
```

Результаты: `build/clean.csv`, `metrics.json`, `rejected.json`, `manifest.json`. Для своего файла: `python pipeline.py --input data/events.csv --output build --as-of 2025-02-01T00:00:00+00:00`.

## Правила

- Зерно входа — одно обращение на строку, уникальный `id`.
- Все строки повторяющегося ключа отклоняются: победитель не выбирается произвольно.
- Метки времени должны содержать часовой пояс; будущее относительно `as_of` отклоняется.
- SLA — закрытие не позднее 48 календарных часов включительно. Знаменатель — валидные закрытые обращения. Открытые обращения в SLA не входят.
- Среднее время — по валидным закрытым обращениям. SLA проверяется по длительности без предварительного округления; только среднее в итоговом JSON округляется до четырёх знаков часа.
- Пропущенная сумма остаётся неизвестной; `known_amount_sum` суммирует только известные значения и не называется выручкой. Денежные значения — Decimal с точностью не больше двух знаков.
- Манифест фиксирует SHA-256 входа, расчётного кода и выходов. Время запуска не включается: повторный запуск с теми же входами даёт те же байты.

В примере 9 строк: 6 приняты, 3 отклонены, 4 закрыты, SLA 75%, сумма известных значений 480.50 условных единиц. Дефектные строки добавлены намеренно.

## Архитектура и ограничения

`CSV → валидация → нормализация → метрики → CSV/JSON + манифест`. Расчёты и файловый ввод разделены. Тесты проверяют сверку количества строк, пограничное значение SLA, дубли, неизвестные значения и воспроизводимость.

Файл обрабатывается в памяти; промышленный ETL, оркестрация, инкрементальная загрузка и подключения к рабочим БД не реализованы. Данные полностью вымышлены, исходники написаны как самостоятельное демо.
