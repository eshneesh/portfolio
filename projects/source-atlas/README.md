# Source Atlas

Локальный каталог CSV-источников с профилями качества, проверкой кардинальности связей и загрузкой в SQLite. Самостоятельный демонстрационный проект на вымышленных данных; без подключений к рабочим системам.

```sh
python atlas.py
python -m unittest discover -s tests -v
```

Python 3.12+, внешних зависимостей нет. Результаты: `build/catalog.json` и `build/atlas.sqlite`; пример каталога — `examples/catalog.json`.

## Что показывает

- Контракт источников и связей задаётся в JSON-манифесте.
- Считаются пустые значения, точные дубли строк, число различных заполненных значений и кандидаты в ключи.
- Фиксируется SHA-256 каждого CSV.
- Проверка связи отделяет пропущенный ключ, orphan-запись и неоднозначный родительский ключ. Оценивается рост количества строк при LEFT JOIN.
- Все источники сохраняются в raw-таблицы SQLite; каталог — в `meta_catalog`. Число строк после загрузки сверяется с профилем.
- Пути источников ограничены каталогом манифеста; повреждённая ширина CSV и повторяющиеся заголовки отклоняются.

В примере шесть событий и четыре записи справочника. Дубли родительского ключа увеличивают LEFT JOIN до восьми строк; одна ссылка не найдена, один ключ пуст. Дефекты намеренные: пример показывает, почему соединение пока нельзя считать безопасным many-to-one.

## Ограничения

Данные читаются в память, размер одного файла ограничен 10 МиБ. Кодировка — UTF-8, разделитель — запятая. Пробельные строки считаются пропусками; непустые ключи сопоставляются точно, без автоматической нормализации. Профили и кардинальность не подтверждают бизнес-смысл связи. `safe_many_to_one` — локальная техническая проверка, а не разрешение на объединение источников.

Учебное хранилище использует SQLite, не DuckDB; полноценные core/mart-слои и промышленная ETL-платформа не заявлены. Корпоративные схемы и исходники не переносились.
