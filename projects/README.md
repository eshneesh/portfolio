# Проекты для портфолио

Семь самостоятельных демонстрационных реализаций: аналитика данных, качество и связи источников, сверка реестров, клиентские когорты, SQL/BI, генерация отчётов и локальный поиск по документам. Все примеры и записи вымышлены. Рабочие репозитории, их история, корпоративный код, оформление и данные сюда не переносились.

| Проект | Что демонстрирует | Начало работы |
|---|---|---|
| [Operations Analytics](operations-analytics/README.md) | Python ETL, контроль качества, воспроизводимые метрики, CSV и JSON | `python pipeline.py` |
| [Report Kit](report-kit/README.md) | Генерация HTML из JSON, проверка контракта, безопасный вывод текста | `python report.py examples/report.json --output build/report.html` |
| [Service BI Lab](service-bi-lab/README.md) | SQL, оконные функции, календарная модель, SLA, Power Query и DAX | `python build.py` |
| [Local Knowledge Search](local-knowledge-search/README.md) | Локальный поисковый индекс, ранжирование, цитаты и оценка качества | `python search.py index` |
| [Source Atlas](source-atlas/README.md) | Каталог CSV, профили качества, проверки JOIN, учебное хранилище SQLite | `python atlas.py` |
| [Ledger Bridge](ledger-bridge/README.md) | Двусторонняя сверка реестров, Decimal, дубли, валюты и журнал исключений | `python bridge.py` |
| [Cohort Compass](cohort-compass/README.md) | Наблюдаемые когорты, ABC/XYZ, неполная история и явные знаменатели | `python compass.py` |

Команды выполняются в каталоге соответствующего проекта. Нужен Python 3.12+. Внешние зависимости, ключи, учётные записи и доступ к БД не требуются.

Проекты объединены в этом репозитории в каталоге `projects/`. Каждый запускается из своей подпапки. При необходимости подпапки можно перенести в отдельные GitLab-репозитории. `.gitlab-ci.yml` включает запуск unit-тестов; доступность Docker runner и образа Python зависит от выбранной площадки. История Git в поставку не включена.

Это портфолио демонстрационных проектов, а не подтверждение промышленного внедрения, экономии времени или количества пользователей. Формулировки для резюме и порядок публикации — в [PORTFOLIO.md](PORTFOLIO.md). Результаты локальной проверки — в [VALIDATION.md](VALIDATION.md).
