# Local Knowledge Search

Локальный поиск по небольшому корпусу Markdown с точными цитатами, номерами строк и хешами документов. Самостоятельное демо retrieval-компонента для будущего RAG: генерации ответов и обращения к LLM здесь нет.

## Запуск

Python 3.12+, без внешних зависимостей и сети:

```sh
python search.py index
python search.py query "SLA compliance closed events"
python search.py evaluate
python -m unittest discover -s tests -v
```

Индекс SQLite хранится в `build/index.sqlite`. Результат запроса содержит `source`, `line`, `text`, `document_sha256`, идентификатор фрагмента и BM25 score. Это релевантные фрагменты, а не готовые выводы модели. Если совпадений нет, возвращается `no_evidence`.

## Как устроено

`Markdown → абзацы → SQLite → токены → BM25 → ранжированные цитаты`.

Индекс строится только по `.md` верхнего уровня указанной папки. Лимиты: 100 документов, 64 КиБ на документ. Ссылки за пределы корпуса и симлинки отклоняются. Обновление содержимого индекса выполняется транзакционно.

Включён авторский вымышленный корпус из четырёх документов на английском и восемь проверочных запросов. Тесты проверяют точность цитаты, повторную индексацию, отсутствие результатов для неизвестной темы и ограничения ввода. Успешность на этом маленьком примере не является оценкой качества поиска на реальных документах.

## Ограничения

Лексический поиск без стемминга, эмбеддингов и перефразирования. BM25 score не является вероятностью достоверности. Любое совпадение термина может дать результат: проверка достаточности доказательств должна добавляться отдельно. Нет авторизации, разграничения доступа или подключения к корпоративной базе знаний. Индекс целиком загружается в память для ранжирования.
