# Cohort Compass

Анализ наблюдаемых клиентских когорт и ABC/XYZ на искусственной месячной панели. Демонстрирует явную обработку границ истории, пропущенных месяцев, нулевой активности и неоднозначного определения «нового клиента».

```sh
python compass.py
python -m unittest discover -s tests -v
```

Python 3.12+, без внешних зависимостей. Результат — `build/analysis.json`, сохранённый пример — `examples/analysis.json`. `--as-of` и `--window` задают последний месяц и длину окна сегментации.

## Когорты

Зерно — один аккаунт за месяц; повторяющийся ключ отклоняется. Когорта определяется первым **наблюдаемым** положительным значением. Это не дата привлечения. Активность на левой границе общей истории и неполная предыстория помечаются `left_censored`.

Для каждой ячейки выдаются размер когорты, число наблюдаемых, активных и ненаблюдаемых аккаунтов. Доля активности считается только среди наблюдаемых; её нельзя трактовать как удержание всей когорты при неполном покрытии. Пустой знаменатель даёт null. Месяцы после `as_of` не достраиваются, будущие входные записи отклоняются.

## ABC/XYZ

- Используются только аккаунты с полным наблюдением каждого месяца окна. Пропущенный месяц не равен нулевому.
- ABC: сортировка по сумме за окно, при равенстве — по идентификатору. Класс определяется накопленной долей **до** включения текущего аккаунта: A до 80%, B до 95%, остальные C. Поэтому группа может пересечь свой порог.
- XYZ: коэффициент вариации по генеральному стандартному отклонению; X ≤10%, Y ≤25%, остальные Z. Пороги демонстрационные, настраиваются аргументами функции `segments`.
- Полностью нулевая серия имеет статус `no_activity`, класс N и неизвестный CV. Неполная серия — `insufficient_history`, без класса.
- Вход содержит неотрицательные суммы в одной условной валюте. Возвраты, перерасчёты, разные валюты и финансовое закрытие потребовали бы отдельного контракта.

Пять вымышленных аккаунтов демонстрируют стабильный поток, переменную активность, нулевое окно, пропуск месяца и наблюдаемое начало активности. Выводы о привлечении, официальном оттоке и причинном эффекте не заявляются. Корпоративный код, клиентские данные и внутренние методики не переносились.
