## Навигация

- [`index.html`](index.html) — главная страница портфолио.
- [`projects/`](projects/) — проекты на Python и SQL: обработка данных, расчёт метрик, проверки качества, отчётность и поиск по документам.
- [`reports/`](reports/) — HTML-отчёты, визуализации и небольшие эксперименты.
- [`assets/`](assets/) — изображения и другие ресурсы сайта.

## Проекты

В [`projects/README.md`](projects/README.md) есть список всех семи проектов, описание каждого и команды для запуска.

Проекты сделаны на демонстрационных данных. В папках лежат исходники, тесты и примеры результатов.
